# Working with me
- I'm using AI to learn, not just to ship. When you make a non-obvious
  decision, explain why in a sentence or two.
- Ask before guessing on ambiguous requirements.
- Prefer small, reviewable changes. One logical change per commit.
- Run the project's tests and linter before saying a task is done,
  and tell me honestly if anything failed.
- Never commit, push, or open a PR unless I ask.
- Don't add dependencies without asking.
- Never put secrets, tokens, or credentials in code or commits.
